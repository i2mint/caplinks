caplinks.passwords#

Password hashing for a link’s password gate: a protocol and a stdlib default.

A link password is a gate, not an account: it is hashed once when the link is made and checked on each unlock. ScryptHasher needs nothing beyond the standard library; anything with the same two methods (an argon2id adapter, say) fits the hasher seam of caplinks.CapabilityLinks.

>>> h = ScryptHasher(n=2**4)  # tiny cost, for the example only
>>> stored = h.hash("correct horse")
>>> stored.startswith("scrypt$"), h.verify(stored, "correct horse"), h.verify(stored, "x")
(True, True, False)

Bases: object

Stdlib hashlib.scrypt, stored as scrypt$n$r$p$salt$hash (base64).

The parameters travel with the hash, so raising n later still verifies old hashes. n=2**14, r=8 costs ~16 MB and tens of ms per check, which a host’s attempt limit (caplinks.limits) bounds.
