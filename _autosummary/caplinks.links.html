caplinks.links#

Capability links: a record behind an unguessable token, with an optional password gate.

Knowing the token is the permission. A record is a plain dict, stored in any MutableMapping keyed by token; the generic fields are RECORD_FIELDS, and a host puts what the link reaches (its scope) in fields of its own beside them:

{"token": "<22 url-safe chars, 128 random bits>",
 "created": "<iso>", "expires": "<iso>" | None,
 "password": "scrypt$..." | None,     # a hash; the password is never stored
 "revoked": "<iso>" | None,           # a tombstone: a revoked link is missing
 ...the host's fields...}

A correct password earns an unlock value (a cookie, for a web host): an HMAC keyed by the stored hash, so a new password, or a revoke, which clears the hash, ends every open session at once.

The store contract: a store that cannot vouch for a record (unreadable, damaged, or missing the host’s own fields) raises KeyError, ValueError or OSError when it is read, and the link is then missing. A record whose generic fields have the wrong types is missing too: every failure closes the link.

>>> links = CapabilityLinks()
>>> rec = links.create({"what": "report-1"}, password="open sesame", expires="7d")
>>> links.status(rec["token"])[0], rec["protected"], "password" in rec
('ok', True, False)

Create, read, list and revoke capability links, and gate them on a password.

store maps token to record (a dict by default, in process); hasher hashes link passwords (stdlib scrypt by default); clock returns the current UTC datetime (tests pin it); min_password_len is the shortest password accepted.

create(fields=None, *, password=None, expires='7d', token=None)[source]#

Make a link carrying the host’s fields; return its record without the hash.

expires is anything caplinks.expiry.parse_expires() reads, 7 days by default ("never" for none); password gates the link. token gates an id that already exists (a host whose links must not change): it must look like a token (check_token()) and be unused; leave it out for a fresh one. The caller then owns the id’s randomness: use 128 random bits, as new_token().

Return type:

dict
