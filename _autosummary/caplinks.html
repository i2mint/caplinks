caplinks#

Capability links: an unguessable token, an optional password gate, expiry, attempt limits.

The parts every app needs to hand someone a link to one thing, with no account: the token is the permission, a password may gate it, it expires, it can be revoked, and password attempts are limited. Standard library only; no web framework. What a link reaches (its scope) and how it is served stay with the app.

>>> links = CapabilityLinks()  # records in a dict; pass any MutableMapping to persist
>>> rec = links.create({"doc": "report-1"}, password="open sesame", expires="7d")
>>> state, stored = links.status(rec["token"])
>>> state, links.check_password(stored, "open sesame")
('ok', True)
>>> cookie = links.unlock_value(stored)
>>> links.unlocked(stored, cookie, max_age_s=3600)
True

create(fields=None, *, password=None, expires='7d', token=None)[source]#

Make a link carrying the host’s fields; return its record without the hash.

expires is anything caplinks.expiry.parse_expires() reads, 7 days by default ("never" for none); password gates the link. token gates an id that already exists (a host whose links must not change): it must look like a token (check_token()) and be unused; leave it out for a fresh one. The caller then owns the id’s randomness: use 128 random bits, as new_token().

class caplinks.ScryptHasher(n=16384, r=8, p=1, salt_bytes=16, dklen=32)[source]#

Bases: object

Stdlib hashlib.scrypt, stored as scrypt$n$r$p$salt$hash (base64).

The parameters travel with the hash, so raising n later still verifies old hashes. n=2**14, r=8 costs ~16 MB and tens of ms per check, which a host’s attempt limit (caplinks.limits) bounds.

class caplinks.SlidingWindowLimiter(*, max_per_window=10, window_s=300.0, max_keys=50000, clock=<built-in function monotonic>)[source]#

Bases: object

At most max_per_window hits per key per window; in memory, per process.

Each worker counts alone (two workers allow twice the attempts); pass a shared limiter when that matters. The least recently seen keys are dropped past max_keys.

>>> t = [0.0]
>>> lim = SlidingWindowLimiter(max_per_window=2, window_s=10, clock=lambda: t[0])
>>> [lim.allow("a"), lim.allow("a"), lim.allow("a"), lim.allow("b")]
[True, True, False, True]
>>> t[0] = 10.0; lim.allow("a")
True

caplinks.parse_expires(value, *, now=None)[source]#

An expiry as an ISO UTC timestamp, or None for never.

None, "" and "never" mean never. Accepts a duration (30m, 12h, 7d, 2w), a date (2026-11-01: the END of that day, UTC, so the link works through the day named), an ISO timestamp (a naive one is UTC), or a datetime. A moment already past is refused.

>>> t0 = datetime(2026, 1, 1, tzinfo=timezone.utc)
>>> parse_expires("2d", now=t0)
'2026-01-03T00:00:00+00:00'
>>> parse_expires("2026-01-05", now=t0)
'2026-01-05T23:59:59+00:00'
>>> parse_expires("never") is None
True
Return type:

str | None
